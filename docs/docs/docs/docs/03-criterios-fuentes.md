# Criterios de Calidad y Sesgo de Fuentes

## Fuentes de datos utilizadas
- AllSides
- Media Bias/Fact Check (MBFC)
- Ad Fontes Media (cuando esté disponible)

## Metodología
- Mostrar el consenso cuando exista entre varias fuentes
- Indicar explícitamente las discrepancias
- Siempre citar el origen de la calificación
- Incluir aviso claro de limitaciones
- No inventar calificaciones propias sin base
