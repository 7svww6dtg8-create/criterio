# Alcance del MVP
**Versión:** 1.0

## Incluye
- Tarjeta de fuente básica (sesgo + calidad aproximada)
- Análisis estructural heurístico con resaltados y tooltips
- Detección y enlace a documentos oficiales + resumen simplificado
- Interfaz mínima (Side Panel o Popup)
- Modo bajo demanda
- BYOK opcional con mitigaciones de sesgo
- Procesamiento local por defecto

## No incluye en el MVP
- Comparación automática de múltiples perspectivas
- Backend propio
- Dashboard de dieta informativa
- Academia interactiva
- Soporte avanzado para redes sociales
