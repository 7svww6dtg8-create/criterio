# Señales que detectará el MVP

## Lenguaje y retórica
- Lenguaje cargado / emocional
- Certeza excesiva o hedging excesivo
- Sensacionalismo

## Atribución y fuentes
- Atribución débil o anónima
- Falta de atribución

## Framing y omisión
- Framing selectivo (nivel básico)
- Posible omisión de contexto

## Documentos oficiales
- Menciones a Código Penal, Código Civil, BOE y leyes principales

## Otras
- Diferencias entre titular y cuerpo
- Estadísticas sin fuente o contexto
